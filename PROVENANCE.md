# Provenance

The initial public skill content was migrated from earlier Sent-authored, MIT-licensed materials. The MIT license is preserved in `LICENSE` and `packages/sent/LICENSE`.

The eight imported public skills were `sent`, `messaging-performance-analyzer`, `rcs-agent-onboarding`, `sender-profile-architect`, `sms-10dlc-registration`, `template-builder-ui`, `waba-embedded-signup`, and `waba-template-author`. Five MCP workflow skills were authored for this package.

This repository is the authoritative public source for the Sent agent plugin. Generated host adapters are derived from `packages/sent` and `adapter-sources` by `scripts/generate_adapters.py`.
