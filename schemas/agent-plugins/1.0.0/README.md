These files are the official Agent Plugins Specification `1.0.0` `plugin.schema.json` and `mcp.schema.json`, pinned locally so release validation is independent of network availability.

Canonical IDs remain unchanged:

- `https://agent-plugins.org/schemas/1.0.0/mcp.schema.json`
